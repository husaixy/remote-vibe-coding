# 极简扁平化设置窗口 · 提案 01

2026-09-10。评审稿，尚未改动 Qt/QML 产品界面。

用浏览器打开 [交互稿](minimal-settings.html)。可切换四个页面、设备类型和连接状态，编辑示例按键映射，查看 Codex 配置指引。所有状态、配置和保存反馈均为演示，不读取本机设备，不调用真实桥接。刷新恢复初始值。

## 视觉与信息层级

- 白色内容区、浅灰导航、单一蓝色强调，无渐变或大面积阴影。
- 以留白、1 px 分隔线和文字层级区分设置；圆角 6 px，主按钮只保留一个。
- 中文字体 Microsoft YaHei，英文 Segoe UI；正文 14 px、辅助说明 12–13 px、页标题 26 px。
- 桌面参考宽度 1080 px，左导航 190 px；内容区内边距 40 px。Qt 落地应覆盖现有 780 × 600 最小窗口、125%/150% DPI 和键盘焦点，不把 HTML 像素值直接当作物理像素。
- 当前交付浅色方向。暗色和 Windows 高对比主题在 Qt 落地时使用同一语义色板验证。

## 页面结构

| 页面 | 主要内容 | 现有实现对应 |
| --- | --- | --- |
| 连接与语音 | 设备、三项独立状态、输出端点、语音触发方式、输入法快捷键 | ConnectionPage.qml |

底部固定保存操作。Qt 实现须保留现有保存校验、重启失败反馈、恢复默认确认、按键检测、设备分支与所有动作选项。原型映射选项仅用于展示编辑方式，不代表删除现有功能。语音键继续使用独立生命周期，不添加双击等待。

## 状态与交互要求

- 桥接进程、普通按键、语音通道分别展示。进程存活不能代表设备连接成功。
- 仅在收到真实按键报告后显示“已收到按键”；重连/断连必须清掉旧会话健康状态。未收到报告显示“等待按键验证”，不要提前显示成功。
- 原型顶部状态切换器用于评审；产品中不出现。正式版状态需由后端可验证事件提供，现有控制器若没有相应字段则补充，不能从进程状态推断。
- 保存成功、桥接停止中、等待枚举、重启成功、启动失败分阶段显示；重启期间禁用重复点击，错误保留用户配置供修正。原型只演示保存提示，尚未模拟完整异步状态机。
- Codex 聚焦说明始终可访问。桥接无法自动确认 Codex 绑定，不能将看过指引标成“检测通过”。固定组合键为 Ctrl+Alt+Shift+F12。
- DJI Mic 2 分支继续显示系统录音输入和硬件说明，不显示遥控器映射或桥接重启。
- 页面切换保留未保存输入；恢复默认继续走当前确认机制。原型“撤销演示修改”只刷新演示页面。

## 落地顺序

1. 确定此稿的信息布局与视觉方向。
2. 调整 Tokens.qml、main.qml 及各页面布局，复用现有控制器与动作模型。
3. 如需三路实时状态，补齐后端状态事件和断连清理，再接入展示。
4. 验证小窗口、DPI、长中文文案、键盘导航、配置保存、旧映射兼容和桥接重启；行为改动按仓库规则构建部署并做真机验证。

本轮仅提交设计稿与使用文档，不将模拟状态接入真实程序。
