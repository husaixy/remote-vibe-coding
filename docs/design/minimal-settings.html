检查与修复

按键和语音分别检查，找到需要处理的环节。

语音正常，普通按键无反应

保存并重启桥接，等待按键通道恢复，再按一次方向键验证。

Codex 打开了，但不能直接输入

用键盘测试聚焦快捷键，再检查主页键的长按映射。

输入框有焦点，语音没有文字

检查输入法语音快捷键和 CABLE 输入、输出方向。

收到真实按键报告后才显示“已收到按键”；启动监听不等于通道健康。

让主页键接上 Codex

首次手动设置一次，之后直接用遥控器唤醒和输入。

  1. 打开 Codex 的 设置 → 键盘快捷键。
  2. 找到 聚焦主聊天 / Focus main chat，绑定：

    Ctrl + Alt + Shift + F12

  3. 先用键盘按这个组合键，输入几个字，确认文字进入当前对话输入框。
  4. 检查主页键长按动作为“唤醒 Codex 并聚焦输入框”，保存并重启桥接。
  5. 切到其他应用，长按主页键约 0.55 秒，再按住语音键说话。
这一步需要你在 Codex 中完成

Remote Vibe Coding 不会自动添加绑定。不同 Codex 版本的命令名称可能变化。
