Remote Vibe Coding 的首个独立 Windows 预发布候选版，把小米蓝牙语音遥控器
2 / 2 Pro（RC001 / RC003）变成 Codex 会话控制器与语音输入面板。

## 主要变化

- 设置窗口改为极简扁平风格，并统一应用、桌面、任务栏和安装器图标。
- 新增 **Codex Micro 风格预设**：遥控器可切换最近会话、调整推理强度、发送、
  批准、拒绝、Fork、新建会话，以及切换 Fast / Plan 模式。
- 修复连接遥控器后，电脑键盘右方向键松开仍让视频网站继续倍速数秒的问题。
- “保存并重启桥接”可清理旧连接，并恢复蓝牙重连后仍处于禁用状态的
  RC001/RC003 HID 按键通道。
- README 补充项目来源、二次开发内容、完整安装步骤、语音链路和排障说明。

## 使用前必须配置 Codex 快捷键

Codex Micro 动作不会自动修改 Codex 设置。安装后请先打开 Codex 桌面版的
**设置 → 键盘快捷键**，将“聚焦主聊天 / Focus main chat”绑定为
`Ctrl+Alt+Shift+F12`，并按项目 README 的快捷键表手动绑定其他 Codex 命令。

确认键单击会先发送 F12 聚焦组合键，等待短暂的 Codex UI 稳定时间，再发送原生
`Enter` 提交当前输入框内容。因此，无需再给 **Send message** 绑定
`Ctrl+Alt+Shift+Enter`。完成其余绑定后，再在 Remote Vibe Coding 的“按键映射”页
应用 Codex Micro 预设并保存。

完整操作说明见 [README](https://github.com/husaixy/remote-vibe-coding#readme)。

## 下载

- `RemoteMicRC003Setup-0.2.0-rc.1-unsigned.exe`：安装版，提供开始菜单和桌面入口。
- `RemoteMicRC003-0.2.0-rc.1-portable-unsigned.zip`：便携版，解压后直接运行。
- `SHA256SUMS.txt`：以上两个文件的 SHA-256 清单。

安装版和便携版二选一即可。两者均未签名，Windows SmartScreen 可能提示；运行前
请先用 `SHA256SUMS.txt` 核对文件哈希。

## 使用顺序

1. 在 Windows 蓝牙设置中配对 RC001 或 RC003。
2. 按 README 配置 VB-CABLE、输入法语音快捷键和 Codex 快捷键。
3. 在设置页选择设备与语音输出端点。
4. 应用 Codex Micro 预设并保存映射。
5. 点击“保存并重启桥接”，再测试普通按键、Codex 命令和麦克风语音。

基础配对、按键与 ATVV 语音链路此前已通过真实 RC001/RC003 设备验收；本候选版
仍可能受到蓝牙固件、Windows 更新、音频端点、输入法版本和 Codex 快捷键设置影响。
